# Official Regional Character Assets

## Daegu: Dodalsu

- Source: Daegu Metropolitan City, "Dodalsu (Otter) Character"
- Official page: https://www.daegu.go.kr/index.do?menu_id=00936490
- Original package: `도달쑤캐릭터_기본형.zip`
- Runtime image: `data/character/daegu-dodalsu.png`
- AI reference sheet: `data/character-reference-sheets/daegu-dodalsu-2d-sheet-approved.png`
- Public license mark shown on the source page: Korea Open Government License Type 2
- Usage: Attribution required. Commercial use is not permitted.

The runtime PNG is an unchanged official emoticon frame distributed on the same
Daegu character page. It is used as the character reference for the non-commercial
competition build.

## Busan: Boogi

- Source: Busan Metropolitan City, Boogi character guide
- Runtime image: `data/character/busan-boogi.png`
- AI reference sheet: `data/character-reference-sheets/busan-boogi-2d-sheet-approved.png`

The runtime image is kept for UI selection. The AI reference sheet is preferred
